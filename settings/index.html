Homey connection, help and information about Light Guard.

🔑 Personal Access Token
Required for Wall Switch automations that use Homey Flows (e.g. Z-Wave remotes like NAMRON). Without this token the app cannot create the flows automatically.

To create a token: go to my.homey.app → Settings → API → Create a Personal Access Token and enable the Flows permission.
Help and getting started
⚡
Light Guard
Control your lights and automations from Homey

Overview and room status

Overview groups enabled and disabled automations by room. Active means the automation is enabled, not that the lights are currently on. Manual light adjustments retain automatic switch-off after no motion. Open a room entry to edit it. Find the activity log under Events.

Night light after movement stops

In Motion → Lights, enable Dim instead of switching off after sunset. Set the brightness (1–100%, default 1%) and optionally a later switch-off, for example 3 hours. The usual hold time runs first, then night lighting starts. New movement returns the lights to their motion brightness and resets the countdown. At sunrise the lights switch off. Daytime behaviour follows the normal switch-off settings. Timers continue through app restarts. Dimmable lights are required.

Getting started
  1. Go to the Devices tab and press Refresh to load all your Homey devices.
  2. Go to Automations and pick a template to create your first automation.
  3. Give it a name, choose your lights, and press Add.
  4. Use a Wall Switch automation to link a button to any group you have created.
Automation templates
🏃
Motion → Lights
Turns lights on when a motion sensor detects movement. After movement stops, use a hold time and optionally fade out. Enable night lighting to dim to an adjustable level after sunset instead of switching off, with an optional later switch-off.
🌙
Smart Dim — Day & Night
Same as Motion → Lights but uses two brightness levels: a bright level during the day and a dim level at night. You set the times when day starts and when night starts. Great for hallways and bathrooms.
🚪
Door → Lights
Turns lights on when a door or contact sensor opens, and optionally off when it closes again. Useful for cupboards, storage rooms, or garage lights.
⏰
Schedule Lights
Runs an action on a fixed time every day (or selected days of the week). You can turn lights ON, OFF, or dim them to a specific level. Good for morning routines or turning everything off at bedtime.
💡
Light Group / Scene
A group of lights with a fixed state. You choose what each light does when the scene runs: set it to a brightness (1–100%) or fully off (0%). The scene does nothing on its own — it is meant to be triggered by a Wall Switch button, another automation, or the Test button. Perfect for a night scene where some lights dim low and others turn off completely.
🔘
Wall Switch / Button
Links a physical switch or button to one or more automations. Each button action (press, on, off, hold) can be mapped to any group you have already created. For devices without standard capabilities, Homey Flows are created automatically.
🏠
Zone Control
Automatically fills in all dimmable lights from a selected Homey zone. Pick the zone and every dimmable light in it is added for you. Optionally attach a motion sensor to trigger it — works exactly like Motion → Lights but scoped to a zone. Also supports lux threshold, active hours, and button override.
⚙️
Custom / Advanced
Build your own automation from scratch. Choose a trigger (motion detected, motion stopped, door opens, door closes, or a fixed time), optionally add a time-range condition, and define one or more light actions. Use this for setups that don’t fit any of the other templates.
⚙️ Optional features (Motion, Smart Dim, Zone Control)
Lux threshold — Prevent automatic switch-on when the room is already bright enough.

Active hours — Restrict automatic switch-on to a time window.

Manual light control — Dim or switch the lights yourself. Motion will keep those values until the room has been empty for the configured inactivity time, then switch off and resume automatic control.

Optional wall button — Assign a remote button to select a manual brightness, or an OFF button to turn off manually. These use the same empty-room time.
💡 Lights tab (inside an automation)
When editing an automation you will see a Lights tab. Here you can set individual brightness levels per light — overriding the global slider. This lets you have one light at 80% and another at 20% in the same automation.

For a Light Group, dragging a slider to 0% turns that specific light OFF when the scene runs, while others stay on at their set level.
Manual light control
Dimming or switching a light manually keeps your chosen light values while the room is occupied. Motion still resets the empty-room countdown. After the configured inactivity time, the lights switch completely off and normal motion control resumes. This also applies when night lighting is enabled. No extra button setup is required when the dimmer or switch reports the light change to Homey.
💬 Tips & common setups
Night scene via wall switch:
1. Create a Light Group called "Night Scene". Add all lights you want to control. In the Lights tab set hallway lights to 5%, bedroom lights to 0%.
2. Create a Wall Switch automation. Map one button to the Night Scene group.
3. Press the button at night — hallway dims, bedroom lights turn off.

Motion lights that dim at night:
Use Smart Dim. Set daytime brightness to 100% and night brightness to 15%. The app automatically picks the right level based on the current time.

Devices not showing up?
Go to the Devices tab and press Refresh. The app caches the device list — a refresh pulls the latest from Homey.

Testing an automation:
Open any automation and switch to the 🧪 Test tab. Press the test button to run the actions immediately without waiting for a trigger.
📋 Events tab
The Events tab shows a timestamped activity log of everything the app has done: triggers fired, conditions checked, actions executed, and any errors. Press Copy Log to copy the full log to your clipboard for troubleshooting.
